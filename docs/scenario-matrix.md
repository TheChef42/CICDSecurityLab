# Scenario Matrix

| Scenario ID | OWASP category | CWE | Scenario title | Vulnerable file(s) | Fixed file(s) | Main weakness | Safe reproduction | Remediation |
|---|---|---|---|---|---|---|---|---|
| SEC03-CWE494 | CICD-SEC-03: Dependency Chain Abuse | CWE-494 | Download of Code Without Integrity Check | `vulnerable/install-unverified.sh` | `fixed/install-verified.sh` | Code is downloaded or executed without checksum, digest, or signature validation. | Run the local script; it executes only a local mock installer. | Verify SHA-256, signatures, or digests before execution. |
| SEC03-CWE829 | CICD-SEC-03: Dependency Chain Abuse | CWE-829 | Inclusion of Functionality from Untrusted Control Sphere | `vulnerable/package.json`, `vulnerable/install-dependencies.sh` | `fixed/package.json`, `fixed/package-lock.json`, `fixed/install-dependencies.sh` | Dependencies are resolved without a lockfile. | Inspect the vulnerable package manifest; no install is required. | Commit a lockfile, pin versions, and use `npm ci`. |
| SEC04-CWE78 | CICD-SEC-04: Poisoned Pipeline Execution | CWE-78 | Improper Neutralization of Special Elements used in an OS Command | `vulnerable/issue-title-search.yml` | `fixed/issue-title-search.yml` | Untrusted GitHub event text is interpolated into shell commands. | Review the workflow file; commands are harmless examples. | Use environment variables, validation, and safe quoting. |
| SEC04-CWE266 | CICD-SEC-04: Poisoned Pipeline Execution | CWE-266 | Incorrect Privilege Assignment | `vulnerable/build.yml` | `fixed/build.yml` | Workflow token grants unnecessary write access. | Inspect workflow permissions only. | Use least privilege such as `contents: read`. |
| SEC06-CWE798 | CICD-SEC-06: Insufficient Credential Hygiene | CWE-798 | Use of Hard-coded Credentials | `vulnerable/deploy.sh`, `vulnerable/app.env` | `fixed/deploy.sh`, `fixed/app.env.example` | Fake credentials are embedded in source files. | Inspect fake test values only. | Read secrets from environment variables or GitHub Secrets. |
| SEC06-CWE532 | CICD-SEC-06: Insufficient Credential Hygiene | CWE-532 | Insertion of Sensitive Information into Log File | `vulnerable/debug-workflow.yml` | `fixed/debug-workflow.yml` | Debug logging can print sensitive environment values. | Review local fake values in workflow YAML. | Avoid environment dumps and mask sensitive values. |
| SEC07-CWE250 | CICD-SEC-07: Insecure System Configuration | CWE-250 | Execution with Unnecessary Privileges | `vulnerable/Dockerfile` | `fixed/Dockerfile` | Container runs with unnecessary root privileges because no `USER` is set. | Build is not required; inspect Dockerfiles. | Create and use a non-root user. |
| SEC07-CWE732 | CICD-SEC-07: Insecure System Configuration | CWE-732 | Incorrect Permission Assignment for Critical Resource | `vulnerable/main.tf` | `fixed/main.tf` | CI/CD IAM policy uses `AdministratorAccess`. | No Terraform apply is required. | Use scoped IAM policy actions. |
| SEC09-CWE354 | CICD-SEC-09: Improper Artifact Integrity Validation | CWE-354 | Improper Validation of Integrity Check Value | `vulnerable/Dockerfile`, `vulnerable/docker-compose.yml` | `fixed/Dockerfile`, `fixed/docker-compose.yml` | Images are referenced by mutable `:latest` tags. | Inspect image references only. | Pin images by immutable digest. |
| SEC09-CWE347 | CICD-SEC-09: Improper Artifact Integrity Validation | CWE-347 | Improper Verification of Cryptographic Signature | `vulnerable/deploy-artifact.sh` | `fixed/deploy-artifact.sh`, `fixed/provenance.json` | Artifact deployment accepts missing or unverified provenance. | Run only against local mock artifacts if desired. | Require provenance or signature verification and fail closed. |

Note: The container privilege scenario uses CWE-250 instead of CWE-16 because CWE-16 is a broad category that MITRE discourages for vulnerability mapping. Earlier broad privilege and artifact mappings have been narrowed where possible: token over-privilege now uses CWE-266, overprivileged cloud identity uses CWE-732, mutable image tags use CWE-354, and unverified provenance uses CWE-347.
